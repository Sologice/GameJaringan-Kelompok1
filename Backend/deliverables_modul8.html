2. Perancangan Skema Database (Entity Relationship Diagram - ERD)
👤 users Entity
PK id INTEGER AUTO
• username VARCHAR(50) UQ
• password_hash VARCHAR(255)
• created_at TIMESTAMP
1 : N (One-to-Many)
🏆 scores Entity
PK id INTEGER AUTO
FK user_id INTEGER (users)
• score INTEGER
• played_at TIMESTAMP
Keterangan Relasi: Tabel users memiliki relasi One-to-Many (1 : N) terhadap tabel scores. Satu akun pengguna (Player) dapat memainkan banyak sesi permainan dan memiliki banyak catatan riwayat skor yang dihubungkan melalui Foreign Key scores.user_id yang mereferensikan Primary Key users.id.
3. Dokumen Spesifikasi Kontrak Endpoint REST API
Method & Path Fungsi Endpoint Payload Input (JSON Request Body) Response Output (JSON Response Body)
GET
/api/health 		Memverifikasi ketersediaan dan status server backend Express aktif. (Tanpa Body / Request Empty) Status: 200 OK { "status": "success", "message": "Game Backend Server is running successfully!", "serverTime": "2026-10-17T07:16:37.512Z" }
POST
/api/register 		Pendaftaran akun pemain baru sebelum masuk ke dalam matchmaking/lobby game. { "username": "player1", "password": "secretpassword" } Status: 201 Created / 200 OK { "status": "success", "message": "User registered successfully", "userId": 1 }
POST
/api/login 		Otentikasi kredensial login pemain dan menerbitkan token sesi permainan. { "username": "player1", "password": "secretpassword" } Status: 200 OK { "status": "success", "message": "Login successful", "token": "eyJhbGciOi...", "userId": 1 }
POST
/api/score/save 		Menyimpan perolehan skor akhir sesi pertandingan (match) pong ke database. { "userId": 1, "score": 150 } Status: 200 OK { "status": "success", "message": "Score saved successfully" }
GET
/api/leaderboard 		Mengambil peringkat Top 10 pemain dengan skor tertinggi secara global. (Tanpa Body / Request Empty) Status: 200 OK { "status": "success", "data": [ { "username": "player1", "score": 250 }, { "username": "player2", "score": 190 } ] }
